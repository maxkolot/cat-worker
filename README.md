# 🐱 Cat Worker

iOS-приложение к доске задач KOLOT Board: серверы «Котик Клайла» и «Котик Колот».

- **Доска** — канбан: Создано → Отправлено → В работе → Фиксы → Тестирование → Готово. Карточки перетаскиваются между колонками долгим нажатием, фильтр по ролям, поиск, новая задача.
- **Боты** — роли проекта: прогресс, текущая задача, «Открыть в ChatGPT» (чат роли), «скопировать следующую задачу и открыть чат».
- **Экраны** — живые рабочие столы ботов (просмотр), пустые слоты — котики.
- **Настройки** — серверы добавляются QR-кодом из панели расширения (⚙ → «📱 QR для Cat Worker»). Ключи доски хранятся в Keychain, в коде их нет.

## Установка (SideStore)

Каждый push в `main` собирает неподписанный IPA в GitHub Actions и публикует релиз.

- Источник для SideStore: `https://github.com/maxkolot/cat-worker/releases/download/source/source.json`
- Или скачать `CatWorker.ipa` из последнего релиза и открыть в SideStore.

SideStore подписывает приложение твоим Apple ID и продлевает подпись раз в 7 дней.

## Разработка

Проект описан в `project.yml` (XcodeGen), `.xcodeproj` генерируется в CI. SwiftUI, iOS 17+.
